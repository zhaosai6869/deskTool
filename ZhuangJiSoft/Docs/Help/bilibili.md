# B站下载

按 BV 号或分享链接下载 B 站视频，免登录，固定 720P 高清 MP4，支持多分 P。

## 打开方式
从主界面点击「🎥 B站下载」卡片进入。

## 设置保存目录（可选）
点顶部「选择目录」选择保存位置。默认保存到「用户下载目录\B站」。

## 下载视频
1. 复制 B 站视频链接，支持两种形式：
   - 完整链接：`www.bilibili.com/video/BV...`
   - 短链：`b23.tv/...`
2. 多分 P 视频：在链接末尾加 `?p=N`（N 是分 P 序号）。
3. 粘贴到输入框 → 点「下载」。
4. 表格「状态」列查看结果（绿色「已下载」/ 红色「失败」，悬停看原因）。

## 记录管理
- 右键某条记录：「重新下载」/「打开文件位置」/「复制链接」。
- 点「清空记录」→ 确认 → 只清历史，不删文件。

## 保存位置与配置
- 默认目录：`用户下载目录\B站`。
- 配置文件：`data\bili_config.json`。
- 下载记录：SQLite 表 `BiliRecords`。

> 提示：固定 720P、一次一条、超时 60 秒、网络错误重试 2 次。清晰度受免登录接口限制，无法下载更高画质或大会员专享内容。
