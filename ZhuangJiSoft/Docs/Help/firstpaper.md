# 第一试卷下载

按学科 / 年级更新题库，筛选后勾选批量下载试卷。

## 打开方式
从主界面点击「📝 第一试卷下载」卡片进入。

## 第一步：更新题库（首次使用）
1. 在「学科」「年级」下拉框选择（切换会联动刷新）。
2. 点「更新题库」联网更新本地题库缓存，右侧显示题库信息。
3. 题库是本地缓存，换学科/年级后需要重新更新。

## 第二步：查询试卷
1. 选「版本」下拉框。
2. 「关键词」可填（如期中 / 期末 / 单元，可留空，点「×」清空）。
3. 点「查询」（回车也可），显示「筛选出 N / 总计 N 份」。

## 第三步：勾选试卷
- 左键点表格行即可切换勾选；「全选本页」/「取消全选」批量操作。
- 用「上一页 / 下一页」翻页继续勾选。
- 右键某行可「下载当前试卷」。

## 第四步：设置命名与保存
1. 「命名规则」可改，支持占位符：`[版本]` `[标题]` `[学科]` `[年级]` `[日期]`；点「×」重置为 `[版本]-[标题]`。
2. 「保存到」设目录：可直接输入或点「浏览...」；「打开文件夹」查看。

## 第五步：下载
点「开始下载」批量下载已勾选试卷。

## 保存位置与配置
- 默认目录：`用户下载目录\第一试卷`。
- 配置文件：`data\firstpaper_config.json`。
- 下载记录：SQLite 表 `FirstPaperRecords`。
