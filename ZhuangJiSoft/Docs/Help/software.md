# 装机软件

常用软件安装包与下载链接的收藏夹。本模块只负责整理链接，不负责真正下载，下载会在系统默认浏览器中完成。

## 打开方式
从主界面点击「🛠 装机软件」卡片进入。

## 新增一条记录
1. 点顶部「新增」按钮，弹出「编辑软件」窗口。
2. 填写「软件名称」（必填，不能为空）和「下载地址」。
3. 点「确定」保存；点「取消」放弃。

## 修改与删除
- 修改：先在表格里选中一行 → 点「修改」→ 弹窗会带出原值 → 改完点「确定」。未选中会提示「请先选择一行再修改。」
- 删除：选中一行 → 点「删除」→ 在确认框「确定删除「xxx」？」里选「是」。

## 下载软件
直接点击表格「下载地址」列里的蓝色超链接，会用系统默认浏览器打开该链接。

## 数据保存位置
记录保存在本地 SQLite 数据库表 `Items` 中，可在设置 →「数据管理」里清空。

> 提示：这里只是链接收藏夹。要真正安装软件，请在打开的网页里自行下载安装。
