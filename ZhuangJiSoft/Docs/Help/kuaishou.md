# 快手下载

粘贴快手分享链接，下载无水印作品。无需登录。一次解析一条。

## 打开方式
从主界面点击「📺 快手下载」卡片进入。

## 设置保存目录（可选）
点顶部「选择目录」→ 在「选择快手下载保存目录」对话框里选位置。默认保存到「用户下载目录\快手」。

## 下载作品
1. 在快手 App 里点「分享 → 复制链接」。
2. 把链接粘贴到输入框（提示文字：粘贴快手分享链接，一次解析一条）。
3. 点「下载」。
4. 表格「状态」列显示结果：绿色「已下载」，红色「失败」（悬停看原因）。

## 记录管理
- 右键某条记录：「重新下载」/「打开文件位置」/「复制链接」。
- 点「清空记录」→ 确认 → 只清历史，不删已下载文件。

## 保存位置与配置
- 默认目录：`用户下载目录\快手`。
- 配置文件：`data\kuaishou_config.json`。
- 下载记录：SQLite 表 `KuaishouRecords`。

> 提示：超时 60 秒，网络错误自动重试 2 次。一次只能解析一条链接。
