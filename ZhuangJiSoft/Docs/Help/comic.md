# 漫画下载

按站点各写一套解析逻辑，粘贴目录页网址抓取图片，打包成 CBZ / PDF。

## 打开方式
从主界面点击「📚 漫画下载」卡片进入。

## 支持站点（固定 4 家）
页面顶部「支持站点」一栏是内置的 4 个站点，**不支持增删改**：

| 站点 | 需要粘贴的网址 | 说明 |
| --- | --- | --- |
| 哔哩哔哩漫画 | 作品详情页 `/detail/mc数字` | 需先登录；目录取全部话数，图片逐页解密导出 |
| 腾讯动漫 | `/Comic/ComicInfo/id/数字` | 章节图片自动解密；付费章节通常只有试读页 |
| 快看漫画 | 作品主题页 `/web/topic/数字`（也支持手机列表页、章节页） | 目录从页面内 `__NUXT__` 数据解析，图片走官方接口；付费/未解锁章节自动取消勾选 |
| 知音漫客 | `/数字/` | 图片取章节页内嵌 `chapter_img_list`（站点会跳到 kanman.com），站点常年不稳定 |

点某个站点名 → 用系统默认浏览器打开该站首页；找到想下的漫画后，复制它的目录页网址回来解析。

## 第一步：解析章节
1. 在「目录页网址」输入框粘贴上面表格中对应形式的完整网址。
2. 点「解析章节」（回车也可），解析中「取消」可用。
3. 章节列表出现在下方表格（章节标题、图片数、状态），右上角显示书名。
4. 中间一栏会显示本次命中的站点与它的使用提示。付费章节会带「🔒」并默认不勾选。

> 若提示「该网址不属于内置支持的站点」，说明域名不在 4 家之内。本模块不再支持任意网址的通用解析。

## 第二步：选择导出格式
默认只勾选「PDF」；可按需再勾「CBZ」，至少选一种，否则提示「请至少勾选一种导出格式（CBZ 或 PDF）」。
- PDF：通用文档格式，浏览器/阅读器都能打开（默认）。
- CBZ：本质是 zip 改后缀，漫画阅读器通用。

## 第三步：勾选章节并下载
1. 左键点表格行勾选章节；「全选」/「取消全选」。
2. 「保存到」设目录（默认 `用户下载目录\漫画下载`，可点「浏览...」或「打开文件夹」）。
3. 点「开始下载」→ 逐章抓图打包。完成后弹窗「下载完成：成功 N 章，失败 N 章」。

## 哔哩哔哩漫画登录（B漫 Cookie）
B 漫接口已关闭匿名访问，不登录会直接报 `code=99`。界面「B漫 Cookie」一行右侧有蓝色「登录」按钮：

1. 点「登录」→ 弹出内嵌官方页（不需要开外部浏览器）。
2. 用扫码 / 账号密码 / 短信任一方式登录，账号密码只提交给 B 站官方页面，不经过本程序。
3. 登录成功后程序自动读取 `manga.bilibili.com` 的 `SESSDATA` 并写入配置，窗口自动关闭，输入框立刻显示凭据。
4. 也可等它自己识别（底部状态栏与诊断日志会实时显示进度）；识别不到时点绿色「✅ 登录完成后点这里保存」，还不行就「复制诊断」把日志发来。

SESSDATA 约 30 天过期，过期后同一入口重新点「登录」即可。也可以手动 F12 复制 SESSDATA 粘到输入框后点「保存」，两条路等价。

> B 漫的作品数据由内嵌网页会话自动采集：章节读官网详情页的完整目录（含全部话数，不再只抓折叠时露出的几章）；图片则在内嵌页面逐页跳转，由官网自身完成风控签名与 DRM 解密后导出为 JPEG。整个过程不需要手动填 Cookie 之外的任何参数，CBZ / PDF 均可正常导出。
>
> 注意：B 漫需要逐页加载页面才能取到已解密的图，因此**每章下载耗时会明显长于其它站点**（章节越长越久），属正常现象，请勿中途关闭。付费/锁定章节能否下载取决于账号是否已购买；未解锁的章节会显示「未找到图片」并跳过。资源版权归原平台及权利人所有，仅供个人学习。

## 配置
`data\comic_config.json`：保存目录、超时 / 重试 / 延时、B漫 SESSDATA。站点解析规则写死在程序里，不在此文件。

> 提示：图片下载会自动带上该站 Referer 防盗链。若状态显示「图片全部下载失败（防盗链？）」，多半是该话需要登录或已失效。资源版权归原平台及权利人所有，仅供个人学习。
