# 漫画下载

按站点各写一套解析逻辑，粘贴目录页网址抓取图片，打包成 CBZ / PDF。

## 打开方式
从主界面点击「📚 漫画下载」卡片进入。

## 支持站点（固定 8 家）
页面顶部「支持站点」一栏是内置的 8 家站点，**不支持增删改**：

| 站点 | 需要粘贴的网址 | 说明 |
| --- | --- | --- |
| 哔哩哔哩漫画 | 作品详情页 `/detail/mc数字` | 走官网接口，只取免费章节 |
| 腾讯动漫 | `/Comic/ComicInfo/id/数字` | 付费章节通常只有试读页 |
| 快看漫画 | 作品主题页 `/web/topic/数字` | 未登录限制较多 |
| 动漫之家 | `/info/数字.htm` | 手机版 `m.dmzj.com` 亦可 |
| 漫画DB | `/comic/数字` | 选简体中文版本再解析 |
| 拷贝漫画 | `/comic/路径名` | 走官方接口，付费章节自动跳过 |
| WEBTOON | `/zh-hant/类型/作品名/list?title_no=数字` | 仅公开免费话 |
| 知音漫客 | `/数字/` | 站点常年不稳定 |

点某个站点名 → 用系统默认浏览器打开该站首页；找到想下的漫画后，复制它的目录页网址回来解析。

## 第一步：解析章节
1. 在「目录页网址」输入框粘贴上面表格中对应形式的完整网址。
2. 点「解析章节」（回车也可），解析中「取消」可用。
3. 章节列表出现在下方表格（章节标题、图片数、状态），右上角显示书名。
4. 中间一栏会显示本次命中的站点与它的使用提示。付费章节会带「🔒」并默认不勾选。

> 若提示「该网址不属于内置支持的站点」，说明域名不在 8 家之内。本模块不再支持任意网址的通用解析。

## 第二步：选择导出格式
勾选「CBZ」和/或「PDF」，至少选一种，否则提示「请至少勾选一种导出格式（CBZ 或 PDF）」。
- CBZ：本质是 zip 改后缀，漫画阅读器通用。
- PDF：通用文档格式，浏览器/阅读器都能打开。

## 第三步：勾选章节并下载
1. 左键点表格行勾选章节；「全选」/「取消全选」。
2. 「保存到」设目录（默认 `用户下载目录\漫画下载`，可点「浏览...」或「打开文件夹」）。
3. 点「开始下载」→ 逐章抓图打包。完成后弹窗「下载完成：成功 N 章，失败 N 章」。

## 配置
`data\comic_config.json`：保存目录、超时 / 重试 / 延时。站点解析规则写死在程序里，不在此文件。

> 提示：图片下载会自动带上该站 Referer 防盗链。若状态显示「图片全部下载失败（防盗链？）」，多半是该话需要登录或已失效。资源版权归原平台及权利人所有，仅供个人学习。
