# 漫画下载

粘贴漫画目录页网址，用通用规则抓取章节图片，打包成 CBZ / PDF。不绑定具体站点。

## 打开方式
从主界面点击「📚 漫画下载」卡片进入。

## 第一步：解析章节
1. 在「目录页网址」输入框粘贴漫画章节列表页的完整网址。
2. 点「解析章节」（回车也可），解析中「取消」可用。
3. 章节列表出现在下方表格（章节标题、图片数、状态），右上角显示当前书名。

## 第二步：识别不准时手动校正（可选）
通用规则是启发式解析，不保证所有站点都正确。若章节或图片抓不到，填 CSS 选择器：
- 「章节选择器」：如 `a.chapter` 或 `#chapter-list a`。
- 「图片选择器」：如 `#content img` 或 `.chapter-content img`。

## 第三步：选择导出格式
勾选「CBZ」和/或「PDF」，至少选一种，否则提示「请至少勾选一种导出格式（CBZ 或 PDF）」。
- CBZ：本质是 zip 改后缀，漫画阅读器通用。
- PDF：通用文档格式，浏览器/阅读器都能打开。

## 第四步：勾选章节并下载
1. 左键点表格行勾选章节；「全选」/「取消全选」。
2. 「保存到」设目录（默认 `用户下载目录\漫画下载`，可点「浏览...」或「打开文件夹」）。
3. 点「开始下载」→ 逐章抓图打包。完成后弹窗「下载完成：成功 N 章，失败 N 章」。

## 配置
`data\comic_config.json`（保存目录、两种 CSS 选择器、超时/重试/延时）。本模块不建 SQLite 记录表。

> 提示：图片下载会自动带上目录页 Referer 防盗链。若状态显示「图片全部下载失败（防盗链？）」，说明该站需要更严格的请求头，属通用解析器的局限。资源版权归原平台及权利人所有，仅供个人学习。
