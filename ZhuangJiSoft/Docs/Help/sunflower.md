# 向日葵

保存向日葵（AweSun）被控端的识别码与访问密码，双击快速发起远程协助。需要先安装向日葵 Windows 客户端。

## 打开方式
从主界面点击「🌻 向日葵」卡片进入。

## 准备：从向日葵客户端获取信息
- 「识别码」：被控端 9 位数字，不带空格。
- 「访问密码」：被控端设置的「无人值守」固定密码。
- 4 位临时验证码会定期刷新，需要在客户端临时输入，本工具不保存，也不用填。
- 官方免费版即可使用。

## 新增记录
1. 点「新增」→ 弹出「编辑 向日葵」窗口。
2. 填「名称」「识别码」「访问密码」「备注」。
3. 点「确定」保存。

## 发起连接（半自动）
1. 双击表格某行：程序先把识别码复制到剪贴板，然后自动拉起并激活向日葵客户端。
2. 屏幕右下角弹出置顶小窗「向日葵连接信息」，显示识别码和访问密码，各有「复制」按钮。
3. 在向日葵客户端的【远程协助】里粘贴识别码即可；点「复制密码」后该小窗 5 秒自动关闭。

## 手动方式
右键某行 →「复制识别码」/「复制密码」/「复制信息」，自行粘贴到向日葵客户端。

## 数据保存位置
SQLite 表 `SunflowerRecords`；识别码与访问密码用 DPAPI 加密保存。

> 提示：官方免费版没有「带 ID + 密码直连」的命令行参数，所以这里只能做到半自动（复制信息 + 拉起客户端），剩下的粘贴动作需要在客户端完成。
