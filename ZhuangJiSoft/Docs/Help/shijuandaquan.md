# 试卷大全下载

从 sjdaquan.com 按站点筛选浏览试卷，勾选后批量下载 PDF。有每日下载配额。

## 打开方式
从主界面点击「📄 试卷大全下载」卡片进入。

## 关于下载配额（重要）
- 未登录：20 套 / 天；登录后：40 套 / 天。
- 真实剩余次数以站点详情页显示为准。点右上角配额文字可从站点重新同步（不消耗配额）。
- 配额用完时「开始下载」按钮会禁用，并提示「今日下载配额已用完，请明天再试或登录账号」。

## 登录（可选，提升配额）
1. 在「用户名」「密码」输入框填站点账号（密码明文显示，仅保存在本机 `data\shijuandaquan_config.json`）。
2. 点「登录」；进入模块时若已保存账号会自动登录一次。
3. 点「退出」退回未登录配额，退出时也会同步配额。

## 筛选与查询
- 用「学科」「年级」「学期」「版本」四个下拉筛选。
- 或在「关键词」框填词点「查询」（站点全文搜索）；「排序」下拉调整顺序。
- 注意：关键词搜索页不支持与左侧筛选组合使用。

## 勾选与下载
1. 左键点表格行勾选；「全选本页」/「取消全选」；翻页继续。右键某行可「下载当前试卷」。
2. 「命名规则」支持占位符：`[标题]` `[版本]` `[年级]` `[类型]` `[年份]` `[日期]` `[编号]`。
3. 「保存到」设目录（默认 `用户下载目录\试卷大全`）。
4. 点「开始下载」。

## 配置
`data\shijuandaquan_config.json`（账号密码、配额记录、保存目录、命名规则）。本模块不建 SQLite 记录表。

> 提示：每次下载前会重新读取站点剩余次数，本地按天计数仅作兜底。为节省配额，不做全站扫描。资源版权归原站点及上传者所有。
