# ssh远程

统一管理 SSH / SFTP 以及 FTP / FTPS 连接，双击打开终端或文件管理窗口。

## 打开方式
从主界面点击「🐧 ssh远程」卡片进入。

## 新增连接
1. 点顶部「新增」按钮，弹出「编辑 SSH/FTP 连接」窗口。
2. 先在「协议」下拉框选类型：
   - `SSH / SFTP`：端口自动填 `22`，双击进终端窗口。
   - `FTP / FTPS`：端口自动填 `21`，双击进文件管理窗口。
3. 填写「名称」（必填）、「主机/IP」（必填）、「端口」「用户名」「密码」「备注」。
4. 点「确定」保存。端口可手动改，协议切换时会自动切回默认端口。

## 连接远端
- 双击某行：SSH 记录打开「终端窗口」（内嵌 WebView2 + xterm.js），FTP 记录打开「文件管理窗口」（SFTP/FTP 上传下载）。
- 也可右键某行 →「打开终端」或「文件管理」。
- 修改：选中 →「修改」；删除：选中 →「删除」→ 确认。

## 测试连通性
- 点顶部「Ping 值」测全部；右键某行 →「测试 Ping」测单条。

## 右键菜单
- 「复制密码」/「复制信息」；「打开终端」；「文件管理」；「测试 Ping」。

## 密码安全
密码用 Windows DPAPI 加密存本机。新建时留空表示连接时手动输入；编辑时留空保留原值。

## 数据保存位置
SQLite 表 `SshRecords`。
