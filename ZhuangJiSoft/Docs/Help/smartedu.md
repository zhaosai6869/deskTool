# 国家中小学智慧教育平台

从国家中小学智慧教育平台按四级筛选浏览电子教材，勾选后批量下载 PDF。必须登录获取凭据。

## 打开方式
从主界面点击「🎓 国家中小学智慧教育平台」卡片进入。

## 第一步：获取登录凭据（必须）
没有凭据时「开始下载」按钮禁用。两种方式：

- **自动登录**：点「登录获取凭据」→ 弹出内嵌官方登录页 → 用账号密码 / 短信 / 扫码在官方页面完成登录 → 程序自动读取凭据并保存。账号密码不经过本程序。
- **手动粘贴**：点「手动粘贴」→ 在弹窗粘贴 JSON 凭据（`{ "access_token": "...", "mac_key": "...", "diff": 0 }`）→ 保存。
- 点「清除」删除凭据。

> 凭据约 7 天过期，失效后需重新登录。匿名下载 PDF 会返回 401/403。

## 第二步：筛选教材
1. 用「学段」「学科」「版本」「年级」四级下拉筛选，切换会联动联网拉取教材清单。
2. 「关键词」框填词后点「查询」。
3. 「刷新目录」可重新拉取标签树与教材清单。

## 第三步：勾选与下载
1. 左键点表格行勾选；「全选本页」/「取消全选」；翻页继续。
2. 右键某行：「下载当前教材」或「在浏览器打开详情页」。
3. 「命名规则」支持占位符：`[标题]` `[学段]` `[学科]` `[版本]` `[年级]` `[出版社]` `[日期]`。
4. 「保存到」设目录（默认 `用户下载目录\国家中小学智慧教育平台`）。
5. 点「开始下载」。

## 配置
`data\smartedu_config.json`（Token、目录、命名规则）。本模块不建 SQLite 记录表。

> 提示：筛选条件取自平台 tag 树，按条件联网拉取清单后本地过滤。资源版权归原平台及权利人所有，仅供个人学习。
