# 视频号下载

粘贴微信视频号分享链接解析下载。需要先登录腾讯元宝（扫码或手机号）才能下载。

## 打开方式
从主界面点击「🎬 视频号下载」卡片进入。

## 第一步：登录元宝（必须）
1. 点顶部「登录元宝」按钮 → 弹出「登录元宝」浏览器窗口。
2. 在页面中完成扫码或手机号登录。
3. 检测到凭据后窗口自动保存并关闭，标题旁「登录状态」变为「已登录元宝（时间）」。
4. 未登录直接点下载会提示「尚未登录元宝，请先点击「登录元宝」完成扫码或手机号登录。」

## 第二步：下载视频
1. 在微信里对视频号内容点「分享 → 复制链接」。
2. （可选）点「选择目录」改保存位置，默认「用户下载目录\视频号」。
3. 粘贴链接到输入框 → 点「下载」。
4. 表格「状态」列查看结果；相同链接会去重，已下载会跳过。

## 退出登录
点「退出登录」→ 确认 → 删除本地凭据（下载记录与文件不受影响）。

## 记录管理
- 右键某条记录：「重新下载」/「打开文件位置」/「复制链接」。
- 点「清空记录」→ 确认 → 只清历史。

## 保存位置与配置
- 默认目录：`用户下载目录\视频号`。
- 配置文件：`data\sph_config.json`；登录凭据由 `YuanbaoAuth` 本地保存。
- 下载记录：SQLite 表 `SphRecords`。

> 提示：凭据失效会提示「登录凭据已失效，请重新登录元宝」。视频编码 H.264 优先，缺失时自动回退 H.265。
