# 网盘直链下载

登录网盘后解析分享链接，用内置多线程下载器把文件下载到本地。支持八家网盘，支持断点续传。

## 支持的网盘
百度网盘、阿里云盘、夸克网盘、UC 网盘、天翼云盘、迅雷云盘、中国移动云盘、123 云盘。程序会根据分享链接自动识别属于哪家。

## 第一步：登录网盘（推荐）
1. 在顶部「选择网盘」区点对应网盘卡片。
2. 点「登录网盘」→ 弹出内嵌官方登录页。
3. 在官方页面完成登录（扫码 / 账号密码 / 短信均可）。
4. 点「登录完成，保存凭据」，程序读取凭据并加密保存在本机。账号密码不经过本程序。
5. 卡片上显示「已登录」即成功。凭据会过期，失效后重新登录即可。

> 大部分网盘取直链都需要登录态。不登录时只能解析少数公开分享，且大概率取不到直链。

## 第二步：解析分享链接
1. 在网盘 App / 网页里复制分享链接。
2. 粘贴到「分享链接」输入框（程序自动识别网盘，也可手动点卡片切换）。
3. 点「解析分享链接」（回车也可），下方列出分享里的文件。
4. 勾选要下载的文件（点行可切换勾选）。

## 第三步：下载
1. 「保存到」设置目录（默认 `用户下载目录\网盘下载`），可点「浏览...」改。
2. 「线程」设并发数，范围 1~32，默认 16。网盘直链一般支持多线程；若某家限速或封链，可调小。
3. 点「开始下载」，表格里显示每个文件的进度和速度。
4. 下载中可点「取消」中止；未完成的分片会保留，重新下载时自动续传。

## 保存位置与配置
- 默认目录：`用户下载目录\网盘下载`。
- 配置文件：`data\pan_config.json`（保存目录、线程数、各网盘加密凭据）。凭据用 DPAPI 加密，明文不落盘。
- 本模块不建 SQLite 记录表。

## 常见问题与限制
- **解析不到文件**：先确认已登录对应网盘；再确认链接有效、提取码正确（如链接带 `?pwd=`）。
- **取直链失败 / 下载 403**：网盘直链接口是各家私有 API，平台改版后可能失效，需更新程序适配；部分正版网盘（如百度）有严格风控。
- **部分网盘解析能力有限**：百度、天翼、迅雷、移动四家的分享文件列表解析依赖登录态和接口版本，能力相对基础，需要用真实分享链接联调。夸克、UC、阿里、123 四家的解析链路更完整。
- 直链有效期通常很短，解析后尽快下载；失效时重新解析。

> 本模块仅解析网盘官方公开 API 获取直链，不破解任何限速机制。仅供个人合法使用，请勿用于盗版分发。资源版权归原权利人所有。
