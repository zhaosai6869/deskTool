# win远程

保存 Windows 远程桌面连接，双击即可一键连上主机。依赖 Windows 自带的远程桌面客户端 `mstsc.exe`。

## 打开方式
从主界面点击「🖥 win远程」卡片进入。

## 新增连接
1. 点顶部「新增」按钮，弹出「编辑 Win 远程」窗口。
2. 填写：
   - 「名称」：便于识别的备注名（必填）。
   - 「主机/IP」：目标电脑的 IP 或主机名（必填）。
   - 「端口」：默认 `3389`，范围 1–65535。
   - 「用户名」：默认 `Administrator`。
   - 「密码」「备注」：按需填写。
3. 点「确定」保存。

## 连接远端
- 双击表格里任意一行，程序会在 `data\` 目录生成临时 `rdp_<Id>.rdp` 文件并调用 `mstsc.exe` 打开远程桌面（默认全屏）。
- 修改：选中一行 →「修改」→ 改完点「确定」。密码栏留空表示保留原密码。
- 删除：选中一行 →「删除」→ 确认。

## 测试连通性
- 点顶部「Ping 值」测全部连接；绿色数字是延迟，红色「未连通」表示 Ping 不通。
- 右键某行 →「测试 Ping」只测这一条。

## 右键菜单
- 「复制密码」/「复制信息」（名称、主机、端口、用户名、密码）复制到剪贴板。

## 密码安全
密码使用 Windows DPAPI 加密后保存在本机。编辑时密码栏留空会保留原密码；新建时留空表示连接时手动输入。

## 数据保存位置
SQLite 表 `RdpRecords`；临时 .rdp 文件在 exe 同级的 `data\` 目录。

> 提示：Ping 用的是 ICMP 探测，有些服务器禁 Ping 但远程桌面仍可连，Ping 不通不代表连不上。
