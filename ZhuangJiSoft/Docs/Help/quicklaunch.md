# 一键启动

按「模式」分组管理一组软件，点一下「一键启动」批量拉起，适合上班、设计、游戏等不同场景。

## 打开方式
从主界面点击「🚀 一键启动」卡片进入。应用清单来自系统已安装程序（注册表 + 开始菜单）。

## 新建模式
1. 点「新建」→ 在输入框填模式名称（如「上班模式」）→ 确定。
2. 用「重命名」「删除」管理已有模式。
3. 在「模式」下拉框选中要配置的模式。

## 往当前模式添加程序（两种方式二选一）
- 方式一：在「应用」下拉框选一个已安装程序 → 点「添加」。
- 方式二：点「浏览…」→ 在文件对话框里选 `.exe` 或 `.lnk` 文件（适合绿色软件）→ 打开即加入。

表格中列出该模式的全部启动项（程序、路径、参数）。同一模式里相同路径不会重复添加。

## 启动
- 点「一键启动」→ 批量拉起当前模式的全部程序。全部成功则静默；有失败会提示「有 N 个程序启动失败：…」。
- 单个操作：右键表格某行 →「单独启动」或「移除此项」。

> 提示：空模式点「一键启动」会提示先从下拉框添加程序。

## 数据保存位置
SQLite 表 `LauncherModes`（模式）和 `LauncherItems`（启动项），可在设置 →「数据管理」里清空。
