# 抖音下载

粘贴抖音分享链接，解析下载无水印视频。无需登录，固定 1080p。一次解析一条。

## 打开方式
从主界面点击「🎵 抖音下载」卡片进入。

## 设置保存目录（可选）
点顶部「选择目录」→ 在「选择抖音下载保存目录」对话框里选位置。默认保存到「用户下载目录\抖音」。

## 下载视频
1. 在抖音 App 里点「分享 → 复制链接」。
2. 把链接粘贴到输入框（提示文字：粘贴抖音分享链接，一次解析一条）。
3. 点「下载」。
4. 在下方表格「状态」列查看结果：绿色「已下载」成功，红色「失败」（鼠标悬停看原因）。
5. 成功后输入框会自动清空；链接无效则保留原文方便重试。

## 记录管理
- 右键某条记录：「重新下载」/「打开文件位置」/「复制链接」。
- 点「清空记录」→ 确认「清空全部下载记录？已下载的文件不会被删除。」→ 只清历史，不删文件。

## 保存位置与配置
- 默认目录：`用户下载目录\抖音`。
- 配置文件：exe 同级 `data\douyin_config.json`。
- 下载记录：SQLite 表 `DouyinRecords`。

> 提示：网络错误、风控、429、5xx 会自动重试 2 次，超时 60 秒。解析依赖分享页数据，链接过期请重新复制。
